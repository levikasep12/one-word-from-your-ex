One word my ex would use to describe me: placeholder. A small Python program that writes that single word to `/output/entry.txt` for make.fun's "One Word From Your Ex" bounty, where an AI judge picks the funniest, most painfully honest word. "Placeholder" beats any insult: it says you were never the destination, only the person kept around until someone better came along.

## Run it

```sh
python3 main.py
```
